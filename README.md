# Materi 5 — Human Computer Interaction dan Visualisasi Data
**Studi kasus:** pengelola perpustakaan ingin mengetahui hari dengan jumlah pengunjung tertinggi. Grafik batang digunakan untuk membandingkan jumlah per hari.

**Menjalankan:**
```bash
pip install -r requirements.txt
python src/visualisasi_pengunjung.py
```
Grafik disimpan di `output/pengunjung_per_hari.png`. Grafik dirancang sederhana dengan judul, label sumbu, dan angka agar mudah dipahami.
